# Microsoft Entra ID Labs

Identity and Access Management labs on **Microsoft Entra ID**. These labs document what I'm learning as I study for the **SC-300: Microsoft Identity and Access Administrator** certification.

| # | Lab | Topics |
|---|---|---|
| 01 | [Manage Users, Groups, Licenses, and Custom Security Attributes](lab-01-manage-users-groups-licenses/) | Users, security groups, dynamic membership, group-based licensing, custom security attributes |
| 02 | [Company Branding, Entra Roles, Custom Roles, and Administrative Units](lab-02-branding-roles-admin-units/) | Sign-in branding, role assignment, role-assignable groups, custom roles, administrative units, custom domains, tenant settings |
| 03 | [External Identities: Guest Users, Cross-Tenant Access, and Collaboration Settings](lab-03-external-identities/) | Guest vs member users, B2B invitations, cross-tenant access settings, identity providers, external collaboration settings |
| 04 | [Hybrid Identity: Entra Connect and Authentication Methods](lab-04-hybrid-identity/) | Hybrid identity, Cloud Sync vs Connect Sync, password writeback, password hash sync, pass-through authentication, federation |
| 05 | [Multifactor Authentication: Methods, Policies, and Registration](lab-05-multifactor-authentication/) | MFA factors, per-user MFA, authentication methods policies, registration campaign, Microsoft Authenticator, My Sign-Ins |
| 06 | [Authentication Methods: Passwordless, FIDO2, and Monitoring](lab-06-authentication-methods/) | Method strength, system-preferred MFA, report suspicious activity, FIDO2, Microsoft Authenticator, Windows Hello for Business, CBA, registration and usage reports |
| 07 | [Self-Service Password Reset (SSPR)](lab-07-self-service-password-reset/) | SSPR licensing, selected-group scope, methods required to reset, security questions, administrator policy, user reset with Authenticator |
| 08 | [Disabling Accounts, Password Protection, and Smart Lockout](lab-08-disable-accounts-password-protection/) | Disable accounts, revoke sessions, reset password, custom banned passwords, password protection for AD, smart lockout |

**Planned focus areas (SC-300 domains):**
- Implement and manage user identities (users, groups, external identities, hybrid identity)
- Implement authentication and access management (MFA, Conditional Access, Identity Protection)
- Plan and implement workload identities (app registrations, managed identities, enterprise apps)
- Plan and automate identity governance (entitlement management, access reviews, PIM)
